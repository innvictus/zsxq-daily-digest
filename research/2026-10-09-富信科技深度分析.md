# 富信科技（688662）：小市值温控器件公司的远期弹性
> 2026-10-09｜Codex独立研究｜v2.1｜基准市值128.6亿元沿用原汇总历史口径，不代表10月9日收盘市值。

## 结论
富信科技评分 **81.5**，排第二。这个结果与原版差异最大：我保留星球中出现的1000亿元远期愿景，同时给出−6的直觉修正。理由很具体：v2.1要求优先使用卖方最高目标，且允许长期愿景；原版以自己假设的25%净利率和“需要110倍PE”为由否决千亿，把一个PS叙事改成PE筛选，不能算单纯的算术证伪。

这并不说明千亿有充分支撑。天风原帖把市场扩容、份额提升、单价上涨连续叠加，却没有为最后的千亿补齐年份与收入桥梁。[F1] 我对它的排序理解是：在这套规则中，富信的远期弹性很强；若比较目标模型的完整程度，杰华特更好。500亿元口径下，富信只有约69.4分。两种结果都写出来，比藏掉目标口径的分歧更有用。

## 基本面：消费电子底盘与通信增量
公司9月24日公告披露，2026年上半年通信收入5616.46万元，占收入19.19%；其中400G、800G、1.6T相关Micro TEC合计销售收入3583.97万元。400G、800G已批量供货，1.6T为小批量，CPO相关产品处于送样验证阶段。公司披露已建成年产2400万片能力，拟募投新增4200万片、建设期3年。[F6]

这些数字用来区分现在和远期，不参与评分折价。特别是“通信收入”不能全部当作1.6T收入，“CPO送样”也不等于已经形成一条收入曲线。深度分析必须把业务口径讲清楚，即使规则允许提前交易长期预期。

| 国产替代方向 | 天风机械9月、国泰海通电新9月均有材料[F3/F4] | 两家券商，不把天风两个团队算两家 |

我不把三年前的华鑫报告凑进2026年共识家数。老报告可以说明长期跟踪，却不能证明今天仍有一家独立团队在重复推荐。两家方向一致计20分，跨天风团队的重复强调体现在推动力度25分。

## 行业与产业链
Micro TEC的作用是局部主动温控。投资上要关注的不是服务器总发热量有多大，而是采用何种激光器、它对温度和波长稳定性有什么要求，以及每个光学组件需要怎样的温控封装。服务器液冷和激光器局部温控处在不同层级，不能直接拿机柜散热投资额当作TEC市场。

卖方叙事有三重增长：光模块总量增加、单模块温控价值量提高、国产供应商份额扩大。三者相乘会产生很大的弹性，也容易算重。例如从四通道变为两通道，单颗器件更贵但颗数减少；如果同时按更多颗数和更高单价外推，就可能把本来替代旧结构的部分当成新增。6月30日纪要已提出硅光可能减少用量，9月材料又强调高性能温控需求，说明需要按具体路线建表。[F2/F5]

我认可先发工艺与客户验证的价值，但不把“买设备只需两三个月”理解为任何竞争者都能立即供货；也不把“认证较久”扩大为永久垄断。这两端之间，才是富信可能获得的价格和份额窗口。

## 预期差
富信最有吸引力的环节是需求增长与份额转移可以同时发生。在客户扩张供应池时，已经进入一些项目的厂商可能获得额外订单，不必等整个行业再增长一倍才增长一倍。对小体量业务，这种变化足以改变市场给公司的分类。

但千亿愿景需要比“从5%到30%份额”更完整的故事。份额是哪一类TEC、用收入还是数量计算、是否包括通信之外应用，都要说明。广义温控市场的份额，不能直接套用到光模块Micro TEC的ASP。我的−6分主要针对这条远期目标的桥梁缺失，并包含单一券商承担高目标定价的集中度；不因当前收入小或扩产慢再扣一次。

## 赔率测算与目标采信
| 情景 | 假设 | 算术结果 | 用途 |
|---|---|---:|---|
| 中期器件量 | 4000万片×40元 | 收入16亿元 | 原帖“近20亿”是宽松近似，非精确值 |
| 原帖第一阶段 | 收入50亿元×10倍PS | 500亿元 | 直接可复算目标 |
| 2028年口径组合 | 全球3亿片×40元×30%份额 | 公司收入36亿元；10倍PS为360亿元 | 说明千亿不能直接贴上2028标签 |
| 千亿反推A | 维持10倍PS、40元、30%份额 | 需100亿元公司收入、全球8.33亿片 | 我的必要条件反推，不是卖方出货预测 |
| 千亿反推B | 全球3亿片、30%份额、40元 | 对应PS约27.8倍 | 我的估值反推 |

关键区别是：原帖的千亿没有明确限定为2028年完成。3亿片是2028年假设，不是永远的市场上限。因此“按2028参数推不出千亿”成立，“长期千亿在数学上不可能”不成立。我按v2.1保留T=1000，并用直觉项反映论证断层。若用户将规则解释为“每个远期目标也必须有同年完整量价模型”，则应选择500亿元替代行，不能把两种口径混成一个结论。

| 指标 | 取值 |
|---|---:|
| T / M | 1000 / 128.6 |
| 目标空间 | +677.6% |
| 空间分 | 100，已封顶 |
| 方向 / 趋势 / 推动力度 | 20 / 30 / 25 |
| C | 75 |
| 基础分 | 87.50 |
| 直觉修正 | −6 |
| **总分** | **81.5** |
| T=500、其他不变 | **69.4** |

空间分在T达到6M，即771.6亿元时封顶。771.6亿元和1000亿元得到相同空间分，这解释了为什么它可以排到第二。它是公式对大弹性标的的偏好，不能把81.5分解读为千亿目标已经被证实。
