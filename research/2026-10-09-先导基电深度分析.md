# 先导基电（600641）：集团能力如何转化为上市公司的新增利润
> 2026-10-09｜Codex独立研究｜v2.1｜冻结市值基准450亿元，来自原汇总的估算值，不是核定的当日行情。

## 结论
先导基电评分 **77.6**，排第三。我接受招商电新1300亿元以上的远期目标，主表取1300亿元，不再额外叠加集团其他资产的价值。最有吸引力的预期，是集团掌握的材料、加工和设备能力可以共同进入SOFC零部件，再通过元朔基电把新增业务与上市公司建立权益联系。[X1]

先导的优势在于可扩展的业务边界：从材料走向部件、从部件走向配套设备，单GW配套价值可能提高。它也因此比单一产品更难估值。覆盖70%的BOM、相应环节50%的份额、上市公司65%的权益是三层不同概念，任意少乘一项都能把想象空间放大很多。研究应当保留高弹性，同时把每一层利润归属写出来。

## 基本面与资产边界
公司9月22日公告确认：上海启芯拟现金认缴1.95亿元，与广东固能共同设立注册资本3亿元的元朔基电，分别持股65%、35%；产品规划包括电解质片、金属连接体、配电设备和超级电容。公告同时提到先导微电子50.63%股权交易及工商变更进展。[X6]

这份公告不能表述成“上市公司以零对价买到广东固能全部成熟资产”。新设合资主体、原有资产转移、旧订单履约、新订单签约分别需要证据。集团能力提供商业起点，上市公司的现金出资和订单归属仍必须讲清楚。这是事实边界校正，不是用公告给远期评分打折。

| 业务 | 卖方描述的作用 | 本文估值处理 |
|---|---|---|
| 凯世通离子注入机 | 半导体设备基本盘 | 已包含在1300亿模型的原有业务估值 |
| 先导微电子 | 电子材料平台 | 不把全部集团材料利润归入上市公司 |
| 铋加工与Micro TEC | 材料加工向高附加值器件延伸 | 作为平台扩展观察，不追加独立千亿故事 |
| 元朔基电 | SOFC材料、部件及BOP配套 | 按65%权益计算归母口径 |
| MFC及科学仪器 | 后续整合想象 | 当前目标之外的叙事观察，不无条件计价 |

上表业务梳理来自中泰10月7日及国金9月材料，资产及客户细节仍以正式公告为准。[X4/X5]

## 星球说法与公开披露
招商、天风、国金、中泰构成本次主叙事的四家独立支持者。华西设备、国联民生设备观点有利于理解原有业务，但不拿来凑成六家一致看好同一个SOFC利润模型。方向一致性计30分，而非40分。

| 关键问题 | 星球说法 | 公开对照/研究判断 |
|---|---|---|
| 1300亿元目标 | 招商假设2028年BE出货8GW、70%可覆盖BOM、50%环节份额[X1] | 是情景测算，不是BE出货承诺 |
| 1000亿元目标 | 天风拆出SOFC约700亿及其他业务300亿[X2] | 可作较低目标敏感性，不与招商分部估值相加 |
| 10亿—20亿美元订单 | 天风9月28日区分集团不同业务[X3] | 原帖预期不能写成元朔已公告订单 |
| 集团资产持续整合 | 国金、中泰持续讨论[X4/X5] | 正式披露已支持部分权益安排，未来安排仍属预期 |
| 海外需求 | Bloom官方Q2业绩及全年指引上修[X7] | 支持SOFC需求趋势，不证明先导取得固定份额 |

## 行业与产业链
SOFC的投资叙事来自数据中心电力需求和现场发电方案。Bloom官方披露2026年二季度收入10.65亿美元，全年收入指引39亿—42亿美元，提供了需求扩张的外部依据。[X7] 从这一事实走到先导的盈利，需要经过客户出货规模、设备BOM、供应商覆盖范围、供货份额和权益比例五步。全球客户高增长只完成第一层，不会自动推出某一家供应商46亿元利润。

我更看重单GW可供产品范围的扩大。材料企业增加连接体或电解质片制造，可能把原料价值提升为加工后的部件价值；再增加电气配套，收入结构会进一步变化。但同一条链上材料卖给内部部件工厂，合并口径应抵销内部销售，不能把材料收入与整套部件收入重复累加。

技术路线也需分清。元朔的商业机会围绕具体客户及具体SOFC体系展开，不能把一个客户的供电方案当成所有燃料电池的共同BOM。平台化能增加选择，但不意味着现有产品自动进入每条路线。

## 预期差
原先市场可能主要按离子注入机看公司，后续电子材料、SOFC会改变比较对象。这种重新分类通常早于合并报表中的利润占比变化，符合v2.1关注预期的目的。我给+4直觉分，来自跨材料、器件和设备的协同叙事，以及多团队在9—10月持续跟踪同一方向。

加分没有使用“老板无偿送资产”这一错误事实，也没有给尚未注入的MFC单独加价。对这类平台，真正能持续增加想象空间的，是后续业务与现有材料、工艺、客户之间有可解释的联系。只把同一集团的所有热门赛道逐个相加，最后会形成一个没有权益边界的目标。

## 赔率测算
招商原帖可以用一个透明模型复算。以下汇率7仅为模型假设，不是对当前汇率的声明：

归母利润 = 8GW × 18亿美元/GW × 70%可覆盖范围 × 50%环节份额 × 20%净利率 × 65%权益 × 7人民币/美元 = **45.864亿元**。

目标估值 = 45.864 × 25倍PE + 原有业务200 = **1346.6亿元**。因此1300亿元以上在原帖参数内成立。[X1]

| 参数变化（其余不变） | 模型市值，亿元 |
|---|---:|
| 客户出货6GW | 1060.0 |
| 客户出货8GW | 1346.6 |
| 客户出货10GW | 1633.3 |
| 环节份额由50%降为40% | 1117.3 |
| 环节份额由50%升为60% | 1575.9 |

这些是我对卖方模型的敏感性计算，既不是新增卖方目标，也不替代主评分T=1300。净利率应作用在可归属的业务收入上，65%权益只乘一次。订单总额也不能不分交货年份就直接当作单年收入。

| 评分项 | 取值 | 原因 |
|---|---:|---|
| T/M及空间 | 1300/450，+188.9% | 最高可复算远期目标 |
| 空间分 | 59.21 | 对数公式 |
| 方向 / 趋势 / 推动力度 | 30 / 33 / 25 | 四家主线支持；需求扩张；连续强推 |
| C | 88 | 不借原有设备主题凑满分 |
| 基础分 / 直觉 / 总分 | 73.60 / +4 / **77.6** | 不受近期利润或订单现实值直接影响 |

若T改为天风1000亿元，分数约70.3。若450亿元基准市值偏差10%，空间分和最终分数也会变化，见汇总敏感性表。此次没有把这个估算市值包装为实时行情。
